Infrastructure

Arvest est une application web adossée à une API ouverte, hébergée sur une infrastructure publique de recherche. Les documents viennent de bibliothèques, du web et de votre ordinateur ; tout est décrit en IIIF, le standard ouvert du patrimoine culturel, et peut donc repartir vers n'importe quel outil IIIF.

1

Des documents de partout

Importez des manifestes IIIF de bibliothèques, d'archives et de musées, ajoutez une image, une vidéo ou un son par son adresse web, ou envoyez vos propres fichiers depuis votre ordinateur. Un document lié reste où il est : Arvest le lit, il ne le copie pas.

  • Qu'est-ce que IIIF ?
2

L'application, dans votre navigateur

Rien à installer : un compte avec une adresse e-mail ouvre tout l'espace de travail, où l'on place, compare, annote et relie les documents. La première version d'Arvest repose sur notre fork du visualiseur IIIF Mirador, qui lit l'audio et la vidéo, avec des plugins pour annoter images et contenus audiovisuels. Arvest v2, en bêta, est un nouvel espace de travail construit sur la même API.

  • Fork AV de Mirador↗
  • Plugin d'annotation d'images↗
  • Plugin d'annotation AV↗
3

Une API ouverte

L'application et vos scripts s'adressent à la même API REST, écrite en NestJS : comptes, groupes, projets, médias, manifestes, métadonnées et annotations. Elle est documentée avec Swagger, et un package Python la rend simple à utiliser dans des scripts et des notebooks de machine learning.

  • Documentation de l'API
  • Code source du serveur↗
4

Conservé chez Huma-Num

Arvest tourne sur une machine virtuelle chez Huma-Num, l'infrastructure publique française pour les humanités numériques. Elle conserve la base de données des comptes et des projets, les fichiers envoyés et les manifestes IIIF qui les décrivent, et une instance PeerTube pour les vidéos volumineuses.

  • Huma-Num↗
  • PeerTube d'Arvest↗
5

Partagé avec le monde

Documents, manifestes et projets entiers se partagent par lien, avec des permissions qui vous laissent décider qui voit et qui modifie. Ce que vous partagez est en IIIF : cela s'ouvre aussi dans d'autres visualiseurs et outils IIIF.

Tout le code d'Arvest est open source
