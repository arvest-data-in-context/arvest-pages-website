Arvest pour Chrome

Collectez le web dans Arvest

Une extension de navigateur qui ajoute à votre compte Arvest ce que vous trouvez sur le web : les images, vidéos et PDF d'une page, chacun comme un document, ou une page ou un site entier capturé en manifeste IIIF, avec tout ce qu'il contient annoté et relié à sa source.

  • Dans votre navigateur
  • Chrome
  • Compte Arvest requis
Télécharger bientôt Code sur GitHub ↗

L'extension arrive sur le Chrome Web Store. En attendant, elle s'installe depuis son code sur GitHub.

01

Collectez les médias de n'importe quelle page

Ouvrez l'extension sur une page : elle liste les images, vidéos, PDF et vidéos YouTube ou PeerTube qu'elle trouve. Un clic ajoute chacun à Arvest comme un document décrit, prêt à placer dans un projet.

02

Capturez une page

Capturez une page telle qu'elle est aujourd'hui. Elle devient un manifeste IIIF : la page entière sur un canevas, avec une annotation sur chaque image, vidéo et bloc de texte qui renvoie à l'original, ainsi que l'adresse et la date de la capture.

03

Archivez un site entier

Suivez les liens d'un site et capturez page après page, aussi loin et autant que vous le décidez, dans un seul manifeste avec un canevas par page. La capture tourne en arrière-plan pendant que vous continuez à naviguer.

Avec Arvest

Tout ce que fait l'extension va directement sur votre compte Arvest : connectez-vous une fois dans ses options, et ce que vous collectez est dans vos documents, prêt pour vos projets.
